# Excel 数据可视化的 Python 复现与实践

基于郭宏远《Excel数据可视化——从图表到数据大屏》的学习实践，使用 Python 复现静态图表、动态图表，以及销售与人力资源可视化看板。

本仓库整理了复现源码、图表成果、交互页面与运行截图，展示从 Excel 图表到 Python 可视化应用的实现过程。

新增国家统计局数据专题，围绕浙江省城市概况与全国人口，制作高清静态图、交互大屏和三维探索页面，并提供原始 Excel 与可复现的 Python 代码。

## 项目内容

| 模块 | 主要内容 | 展示形式 |
|---|---|---|
| 第二章：前15图 | 柱形图、折线图、甘特图、圆环图等 | PNG、SVG |

| 国家统计局：全国人口 | 人口总量、年龄性别、城乡结构与普查画像 | PNG、HTML、Python |

## 交互功能

### 销售看板

- 支持1—12月切换，联动更新销量、成本、利润及商品排名。
- 支持月份自动播放、暂停及恢复9月。
- 展示产品类别、区域、快递公司等维度的销量分布。
- 展示全年销售趋势和商品销售额 Top3。

### 人力资源看板

- 展示年龄、性别、婚姻状况、学历、部门与入转调情况。
- 支持部门和性别筛选，人数与图表同步更新。
- 支持图形悬停查看详细数值。

## 国家统计局数据可视化

新增目录 [国家统计局数据可视化](国家统计局数据可视化/) 包含两个专题。每个专题保留下载的原始工作簿、10 张静态 PNG、2 个交互大屏、1 个三维探索页，以及对应 Python 代码。

合计 **20 张 4800×2700 / 300 dpi PNG、6 个离线 HTML、17 份 Excel、10 个 Python 文件**。

| 专题 | 静态图 | 交互页面 |
|---|---|---|
| 浙江省城市概况 | [10 张 PNG](国家统计局数据可视化/浙江省城市概况/可视化/) | [城市运行大屏](国家统计局数据可视化/浙江省城市概况/可视化/11_城市运行大屏.html) · [城市设施观察台](国家统计局数据可视化/浙江省城市概况/可视化/12_城市设施夜景大屏.html) · [三维城市探索](国家统计局数据可视化/浙江省城市概况/可视化/13_三维城市探索.html) |
| 全国人口 | [10 张 PNG](国家统计局数据可视化/全国人口/可视化/) | [人口变化图谱](国家统计局数据可视化/全国人口/可视化/11_人口变化图谱.html) · [人口结构观察台](国家统计局数据可视化/全国人口/可视化/12_人口结构观察台.html) · [人口三维探索](国家统计局数据可视化/全国人口/可视化/13_人口三维探索.html) |

- **浙江省城市概况**：公共出行、轨道网络、供水结构、燃气转型、道路管网、绿色空间及环卫设施。两套大屏采用不同专题和布局；三维页支持旋转与年份选择。
- **全国人口**：年度人口变化、出生死亡、城乡与年龄结构、抚养比、年龄金字塔、热力图、性别比、教育程度和预期寿命。三维页支持“年度人口轨迹 / 样本年龄脊线”切换、旋转缩放、年份播放和视角复位。

HTML 已内嵌数据和 Plotly.js，下载后可直接离线打开；同一专题的三个 HTML 放在同一目录即可相互切换。三维探索需要浏览器支持 WebGL。GitHub 文件页用于查看文件，不会自动运行 HTML。

## 如何运行

### 1. 下载项目

在仓库页面点击 **Code → Download ZIP**，下载并解压，保留原有文件夹结构。

### 2. 安装依赖

建议使用 Python 3.10 或以上版本。

运行 Streamlit 看板需要：

```bash
python -m pip install streamlit plotly openpyxl
```

如果还需要重新生成第二章的静态图表：

```bash
python -m pip install matplotlib numpy pillow
```

### 3. 启动 Streamlit 看板

在解压后的项目根目录打开终端，执行：

```bash
cd "第四章可视化/Streamlit版"
python -m streamlit run app.py
```

启动后，打开终端显示的本地网址。演示期间保持终端运行，结束时按 `Ctrl+C` 停止服务。

程序会自动查找项目中的“原文件”目录，也可以在侧栏“数据位置与刷新”中手动指定数据位置。

### 4. 在 Jupyter 中启动

打开 `Jupyter启动看板.ipynb`，将第一个单元格中的 `folder` 改为自己电脑上“Streamlit版”文件夹的实际路径，再依次运行代码单元格。

Notebook负责启动服务，看板在独立浏览器页面显示。

### 5. 查看离线网页版

下载项目后，直接用浏览器打开“网页版”目录中的 HTML 文件即可。

GitHub首页用于展示源码、说明和截图；上传仓库不会自动部署 Streamlit，也不会将本地网址变成公开演示地址。

### 6. 重新生成国家统计局专题

安装该专题依赖：

```bash
python -m pip install "matplotlib>=3.8" "plotly>=5.24" numpy pillow openpyxl
```

在项目根目录执行以下命令，每个命令生成对应专题的 10 张 PNG、2 个大屏及 1 个三维页：

```bash
python "国家统计局数据可视化/浙江省城市概况/可视化/python/regenerate_all.py"
python "国家统计局数据可视化/全国人口/可视化/python/regenerate_all.py"
```

默认使用生成器内嵌的原始数据快照，不依赖本机绝对路径；也可通过 `--data-dir` 指向对应专题的 `国家统计局数据` 目录读取 Excel。输出位置与只生成 PNG / HTML 的参数可运行 `--help` 查看。

生成中文 PNG 需安装 Microsoft YaHei、Noto Sans SC 或 SimHei 等中文字体。直接查看已经生成的 PNG 和 HTML 无需安装 Python。

## 代码分工

| 文件 | 作用 |
|---|---|
| `app.py` | 页面布局、筛选控件、月份切换与自动播放 |
| `data_model.py` | 读取 Excel、筛选明细与汇总统计 |
| `charts.py` | 使用 Plotly 构建图表 |
| `.streamlit/config.toml` | 页面主题与服务配置 |

`data_model.py` 和 `charts.py` 由主程序调用，不需要分别运行。

新增专题的 `可视化/python/` 中，`regenerate_all.py` 是一键复现入口，数据模块保存原始快照与统计说明，其他模块分别生成静态图、交互大屏和三维探索。

## 数据口径与复现说明

- 销售“销量”沿用原表的明细行数统计口径，不代表去重订单数或产品件数。
- 销售额和利润额以“万”为单位；成本保留源表数值。
- 原表标注的“同比”实际为月度环比，Python看板中已更正；1月缺少上年12月数据时不计算环比。
- 人员表中“专科以下”和“专科”的汇总公式引用颠倒，已按明细修正，并在看板中说明。
- 复现保留主要图型、配色与布局，同时增加适合 Python 应用的交互功能。
- 国家统计局专题保留缺失，不补零、不插值；具体单位、分母与计算方式见 HTML 数据说明及 Python 注释。
- 全国人口的年度数据覆盖 2016—2025，年龄分组抽样提供 2016—2024 的有效年份（不含 2020），人口普查及预期寿命为 2020 年。样本人数与全国人口分别呈现。
- 浙江省城市概况主要覆盖 2016—2024；部分城市建设指标的可用年份较短，按原表实际数据展示。
